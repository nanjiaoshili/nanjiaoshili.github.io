# 南郊势力

大秦军团南郊势力战斗组官方网站。

## 比赛相册

影像页（`gallery.html`）的「比赛相册」按比赛归档现场照片，点开可全屏浏览（← → 翻页、Esc 关闭、手机左右滑动）。

**新增一场比赛的相册：**

1. 把原图放进任意临时目录（例如 `images/20261108`）。
2. 运行压缩脚本（自动转正方向、生成高清图与缩略图）：

   ```bash
   python tools/build-album.py images/20261108 20261108
   ```

   生成 `images/albums/20261108/full/01.jpg…` 与 `thumb/01.jpg…`，并打印一条配置。
3. 把打印出的配置追加到 `js/albums.js` 的 `ALBUMS` 数组，填入对阵双方、日期、场地：

   ```js
   { id: "20261108", title: "陕西联合 VS 对手", date: "2026.11.08", venue: "西安国际足球中心", cover: 1, count: 60 }
   ```

4. 保存后页面会自动出现新的相册卡片，无需改动其它代码。原图不必上传（体积太大），只提交 `images/albums/` 下压缩后的文件即可。

**照片有增减时：** 直接重新运行同一条命令即可。脚本会先清空该相册的旧图、按顺序重新编号（01–N 连续，不会断号），并打印新的照片数量；把 `js/albums.js` 里这条相册的 `count` 改成打印出的数字即可。
